# 南网在线 · Home Assistant 集成

把南方电网「南网在线」（[95598.csg.cn](https://95598.csg.cn/)）的余额、电量、电费接入 Home Assistant，逐日用电量还能直接用在**能量面板**里。

- 只做查询：不缴费、不绑定、不改资料。
- 非官方项目，官方网站改版后可能需要更新才能继续使用。

## 功能

- 手机号 + 短信验证码登录，或导入浏览器里的登录 token
- 自动发现账号下所有绑定户号，每个户号一个设备
- 余额、欠费、今年/上个账单月/本月的电量和电费、最近一日电量
- 逐日用电量按真实日期进入能量面板
- 每天 0 点、12 点自动刷新；登录失效时提醒重新登录

## 要求

- Home Assistant **2025.6** 或更新

## 安装

**一键添加**（HACS 和 Marketplace 都能用）：

[![打开 Home Assistant 并添加本仓库](https://my.home-assistant.io/badges/hacs_repository.svg)](https://my.home-assistant.io/redirect/hacs_repository/?owner=ywandy&repository=nanwang_hass&category=integration)

**HA 2026.10 及以前（HACS）**

1. HACS → 右上角 ⋮ → 自定义存储库
2. 填 `https://github.com/ywandy/nanwang_hass`，类别选 **Integration**，添加
3. 搜索「南网在线」并下载，然后重启 Home Assistant

**HA 2026.11 及以后（设置 → Marketplace）**

点上面的一键链接，按提示添加本仓库、下载，然后重启 Home Assistant。

**手动安装**

把 `custom_components/nanwang` 整个文件夹复制到 Home Assistant 配置目录下的 `custom_components/` 里，然后重启。

## 添加集成

设置 → 设备与服务 → 添加集成 → 搜索「南网在线」，二选一：

**手机号 + 短信验证码（推荐）**

1. 填写手机号，选择所在地区
2. 收到短信后填入验证码

**导入浏览器 token**

1. 用电脑浏览器登录 https://95598.csg.cn/
2. 按 F12 打开开发者工具 → Application（应用）→ Session Storage → `https://95598.csg.cn`
3. 复制 `token` 的值（`custnumber` 可选），粘贴到表单里

### 登录失效后重新登录

登录过期后，设置 → 设备与服务 页面顶部会出现「南网在线」的提醒：

1. 点 **重新认证**
2. 选择短信登录（会自动带出原来的手机号）或导入 token
3. 完成后会立刻刷新数据，原有的实体和历史记录都会保留

> 如果在别的地方（例如另一台设备上的网页）用同一个 token，可能会把 Home Assistant 这边顶下线，重新登录即可。

## 实体说明

每个户号是一个设备，名称为「南网 户号」，例如「南网 0800xxxxxxxxxxxx」。

| 实体 | 说明 |
|---|---|
| 电费余额 | 账户余额（元） |
| 欠费金额 | 当前欠费（元） |
| 锁定余额 | 被锁定、暂不可用的余额（元） |
| 今年电量 / 今年电费 | 今年已出账单的累计电量和电费，每年 1 月 1 日清零 |
| 最近账单月电量 / 电费 | 最近一个已出账单月份的电量和电费，属性里有账单月份 |
| 最近账单月均价 | 最近账单月的电费 ÷ 电量（元/kWh） |
| 本月电量 | 本月到目前为止的用电量，每月 1 日清零 |
| 本月预估电费 | 本月电量 × 最近账单月均价，**仅供参考，不是账单金额** |
| 最近一日电量 | 最近一天的用电量，属性里有具体日期 |

几点说明：

- 南网的逐日数据一般**晚 1~2 天**才出，所以「最近一日电量」通常是前一两天的。
- 当月账单要到下个月才出，所以「最近账单月」一般是上个月。
- 官方没有提供每天或当月的电费，「本月预估电费」是按均价估算的。
- 余额、欠费以南网返回为准；后付费的户号可能一直显示 0。
- 长期没用电的户号（例如充电桩）可能显示 0 或「未知」，属正常现象。
- 新绑定的户号，需要在集成页面点 ⋮ → **重新加载** 后才会出现。

## 能量面板

集成会把每天的用电量按实际日期写入「南网 户号 用电量」统计（首次添加时会补上最近 6 个月）。

设置 → 仪表盘 → 能量 → 电网用电量 → 添加，选择「**南网 户号 用电量**」即可。

> 请选这个统计，**不要**选「本月电量」传感器：南网数据有延迟，用传感器的话用电量会被算到数据更新的那天，而不是实际用电的那天。

## 隐私

- 登录信息只保存在你自己的 Home Assistant 里。
- 「下载诊断」导出的文件里，token、手机号、户号、户名、地址等都会自动打码，可以放心发给别人排查问题。

## 常见问题

**数据很久没变化？**
集成只在每天 0 点、12 点刷新，南网的数据本身也会晚 1~2 天。想立刻刷新：设置 → 设备与服务 → 南网在线 → ⋮ → 重新加载。

**提示需要重新认证？**
登录已过期，按上面「登录失效后重新登录」操作即可。

**收不到验证码 / 提示获取太频繁？**
南网对验证码有频率和次数限制，等一段时间（有时要到第二天）再试，或改用导入 token 的方式。

**遇到其它问题**
到 [Issues](https://github.com/ywandy/nanwang_hass/issues) 反馈，最好附上「下载诊断」的文件（设置 → 设备与服务 → 南网在线 → ⋮ → 下载诊断）。需要更详细的日志时，在 `configuration.yaml` 里加上：

```yaml
logger:
  logs:
    custom_components.nanwang: debug
```
